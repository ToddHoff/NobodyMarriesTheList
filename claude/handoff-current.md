### Working notes (tools)

- Project files are read whole with the Projects tool and written back whole (`project_write` with `local_path`). Subagents cannot read the project: put what they need on local disk first (this session used `nmtl/manuscript/`, `nmtl/claude/` and `nmtl/review/`).
- Docs: a search read (`{"kind":"search","text":...}`) finds a paragraph; `replace` with a find target and `"as":"text"` changes words across runs (that is how the header time is changed); a whole paragraph is replaced by block id with `ifHash` and `ifRev`; a new chapter goes in with an `insert` at `{"kind":"root"}`, `"side":"end"`, as markdown. An in-page link cannot ride a span-grade replace: to rebuild the Jump-to row, insert a new markdown paragraph after the old row and delete the old block with its guards, in one call.
